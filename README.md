# Proyek Database Sekolah (Stupen Celerate)

## 📖 Deskripsi Proyek
Proyek ini adalah tugas yang dikerjakan sebagai bagian dari program **Stupen Celerate**, dengan fokus pada pembelajaran backend menggunakan **database PostgreSQL**.

## 🚀 Tujuan dari tugas ini adalah untuk mempraktikkan keterampilan manajemen database dasar, termasuk:
* Merancang dan membuat skema database relasional sederhana.
* Membuat tabel untuk mengelola data siswa dan nilai.
* Melakukan operasi data fundamental seperti `INSERT`, `SELECT`, `UPDATE`, dan `DELETE`.
* Menggunakan `JOIN` dan `GROUP BY` untuk melakukan query data yang lebih kompleks.

Seluruh proses pengembangan skrip SQL ini juga didokumentasikan menggunakan Git untuk kontrol versi.

---
## 🛠️ Teknologi yang Digunakan
* **Database:** PostgreSQL
* **Kontrol Versi:** Git & GitHub
* **Alat Klien DB:** DBeaver
